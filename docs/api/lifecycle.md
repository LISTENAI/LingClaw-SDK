# 生命周期

最低 API 版本：2。应用通过定义以下全局函数接收运行器回调。

## on_start()

最低 API 版本：2。可选回调。

**作用：** 初始化应用状态和画面，在源码执行完成后调用一次。

**参数：** 无。**返回值：** 忽略。

## on_tick(dt_ms)

最低 API 版本：2。必须定义。

**作用：** 更新动画、计时或其他需要定期执行的逻辑。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| dt_ms | integer | 本次逻辑步长，单位毫秒，当前为 20 |

**返回值：** 忽略。

正常每 20 ms 调度一次。系统繁忙或应用暂停时，实际间隔可能更长。
`dt_ms` 适合推进动画；显示日历时间应使用 [clock](clock.md)。

## on_exit()

最低 API 版本：2。可选回调。

**作用：** 在正常退出时完成清理。

**参数：** 无。**返回值：** 忽略。

异常终止或实例替换不保证执行此回调。需要保留的数据应及时保存，
不要等到退出时才调用 `storage.save()`。

## 执行顺序

启动时依次执行源码、`on_start()` 和第一次 `on_tick(20)`。
启用屏幕时，这三个阶段合计至少调用一次 `screen.present()`。
后续回调串行执行；旧实例的异步结果不会交付给替换后的新实例。

按键、HTTP 和播报回调分别见[输入](input.md)、[http](http.md)、[tts](tts.md)。
