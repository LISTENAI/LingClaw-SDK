# led · 指示灯

最低 API 版本：2。需要 `hardware.lighting.leds` 声明至少一个指示灯。
所有接口的 `id` 均取自该列表；未知 ID 会产生 Lua 异常。

## led.on(id)

最低 API 版本：2。

**作用：** 打开指定指示灯并保持常亮，覆盖原来的闪烁状态。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 指示灯 ID |

**返回值：** 无。

## led.off(id)

最低 API 版本：2。

**作用：** 关闭指定指示灯，取消原来的闪烁状态。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 指示灯 ID |

**返回值：** 无。

## led.blink(id, on_ms, off_ms)

最低 API 版本：2。

**作用：** 持续闪烁，直到下一次指示灯操作或应用退出。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 指示灯 ID |
| on_ms | integer | 每次亮起时长，10–5,000 毫秒 |
| off_ms | integer | 每次熄灭时长，10–5,000 毫秒 |

**返回值：** 无。
