# buzzer · 蜂鸣音

最低 API 版本：2。需要 `hardware.audio.speaker` 为 `true`。

## buzzer.play(hz, ms)

最低 API 版本：2。

**作用：** 异步播放一个指定频率和时长的单音。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| hz | integer | 频率，100–5,000 Hz |
| ms | integer | 持续时间，20–3,000 毫秒 |

**返回值：** 无。

队列最多容纳 4 项，队列满时丢弃新增音效。播放使用系统音量，
其他音频活动可能中断或抑制蜂鸣音，因此不能用它作为必须送达的通知。

```lua
buzzer.play(880, 100)
```

模拟器通过电脑默认音频设备播放方波，可在底栏静音。
